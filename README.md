# USB DFU загрузчик для Миландр

Компактный загрузчик USB DFU (Device Firmware Upgrade) для микроконтроллеров Миландр К1986ВЕ92F1I (MDR1211F1I), созданный по спецификации USB DFU. Он позволяет прошивать микроконтроллер по USB с использованием стандартных утилит, таких как `dfu-util`.

## Возможности
- Протокол USB DFU (версия 1.1): использует конечную точку 0 для управляющих передач и специфичных для класса запросов.
- Условия входа:
  - Состояние кнопки GPIO (вывод PB6 нажат/замыкается во время загрузки или сброса).
  - Программный сброс (запись магического значения `0xDEADBEEFCC00FFEE` в конец SRAM).
  - Отсутствие валидного пользовательского приложения во Flash (проверка корректности указателя стека SP и вектора сброса Reset Handler PC).
- Индикация состояния: светодиод на выводе PB7 мигает, когда загрузчик находится в режиме DFU.
- Конфигурируемость: ключевые параметры (выводы, активные уровни, USB VID/PID, разметка памяти) вынесены в файл `src/config.h`.

## Разметка памяти

Флеш-память микроконтроллера имеет общий размер 128 КБ с размером страницы 4 КБ. Память разделена следующим образом:

| Область | Начальный адрес | Размер | Описание |
|---|---|---|---|
| **Загрузчик** | `0x08000000` | 8 КБ | Зарезервировано под данный загрузчик |
| **Пользовательское приложение** | `0x08002000` | 120 КБ | Раздел памяти, куда прошивается пользовательское ПО |

### Изменение линкер-скрипта пользовательского приложения
Чтобы связать ваше приложение для работы совместно с загрузчиком, обновите его линкер-скрипт (обычно `MDR32F9Q2I.ld`) следующим образом:

```ld
/* ДО ИЗМЕНЕНИЯ: */
MEMORY
{
  FLASH(rx) : ORIGIN = 0x08000000, LENGTH = 128K
  RAM(xrw)  : ORIGIN = 0x20000000, LENGTH = 32K
}

/* ПОСЛЕ ИЗМЕНЕНИЯ: */
MEMORY
{
  FLASH(rx) : ORIGIN = 0x08002000, LENGTH = 120K
  RAM(xrw)  : ORIGIN = 0x20000000, LENGTH = 32K
}
```

## Компиляция и прошивка загрузчика (через программатор)

Вы можете собрать и прошить загрузчик с помощью готового bash-скрипта:

```bash
./build_and_flash.sh [OPTIONS]
```
Этот скрипт автоматически очистит директорию сборки, запустит CMake, скомпилирует загрузчик и прошьет файл `milandr_dfu_bootloader.bin` через OpenOCD с использованием отладчика.

Параметры скрипта:
- `-c`, `--clean` — выполнить чистую сборку (удалить директорию `build` перед компиляцией).
- `-f`, `--flash` — прошить собранный загрузчик через отладчик (OpenOCD).
- `-h`, `--help` — показать справку по использованию.

По умолчанию запуск без параметров выполняет обычную сборку без очистки и без прошивки.

Альтернативный вариант ручной сборки:

```bash
mkdir build
cd build
cmake ..
make
```

В результате будут созданы бинарные файлы:
- `milandr_dfu_bootloader.bin`
- `milandr_dfu_bootloader.hex`

## Инструкция по установке dfu-util

Для взаимодействия с загрузчиком на стороне хоста необходима утилита `dfu-util`:

### Windows
1. Скачайте последние версии бинарных файлов со страницы релизов dfu-util.
2. Распакуйте архив и добавьте путь к папке с `dfu-util.exe` в системную переменную PATH.
3. Установите USB-драйвер с помощью программы **Zadig**:
   - Подключите устройство Миландр в режиме DFU (зажав кнопку PB6 при сбросе).
   - Откройте Zadig, выберите *Options* -> *List All Devices*.
   - Выберите DFU-устройство Миландр (по умолчанию VID/PID: `1209:be92`).
   - Укажите **WinUSB** в качестве целевого драйвера и нажмите *Replace Driver* или *Install Driver*.

### macOS
Установка через пакетный менеджер Homebrew:
```bash
brew install dfu-util
```

### Linux (Ubuntu/Debian)
Установка через пакетный менеджер apt:
```bash
sudo apt-get update
sudo apt-get install dfu-util
```
(Опционально) Добавление правила udev для прошивки без прав суперпользователя:
Создайте файл `/etc/udev/rules.d/45-milandr-dfu.rules` со следующим содержимым:
```udev
SUBSYSTEMS=="usb", ATTRS{idVendor}=="1209", ATTRS{idProduct}=="be92", MODE:="0666"
```
Затем перезагрузите правила udev:
```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
```

## Пример проекта: Blink

Готовый пример приложения находится в папке `example_blink`. Он настроен на работу со смещением по адресу `0x08002000` и управляет светодиодом на выводе PB7.

### Компиляция и прошивка примера

Для удобства сборки и прошивки примера подготовлен аналогичный скрипт:

```bash
cd example_blink
./build_and_flash.sh [OPTIONS]
```

Параметры скрипта:
- `-c`, `--clean` — выполнить чистую сборку примера.
- `-f`, `--flash` — прошить скомпилированное приложение в плату по USB через `dfu-util` (в режиме DFU).
- `-h`, `--help` — показать справку.

### Инструкция по перепрошивке через DFU:
1. Подключите плату Миландр к USB, зажмите кнопку на выводе PB6 и кратковременно нажмите Reset для перехода в режим DFU (светодиод на PB7 начнет мигать).
2. Запустите скрипт прошивки:
   ```bash
   ./build_and_flash.sh --flash
   ```
   Этот скрипт автоматически вызовет `dfu-util` со следующими параметрами:
   ```bash
   dfu-util -a 0 -d 1209:be92 -D build/blink.bin
   ```
3. Сбросьте плату (Reset). Светодиод на PB7 начнет мигать с постоянным интервалом в 500 мс.
